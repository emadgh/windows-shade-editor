# Shade Editor 0.6.0

## Default DPI

Shade Editor reads TIFF XResolution/YResolution/ResolutionUnit when they form a valid physical resolution. When a TIFF has no valid physical DPI, the application uses the user-configurable **Default DPI** from Settings. The factory default is **220 DPI**.

The effective DPI is used consistently for Test Code point sizing and centimeter margins. When exporting a source TIFF that did not provide valid physical DPI, Shade Editor writes the configured fallback as inch-based TIFF XResolution/YResolution metadata.

## Channel palettes

Channel palettes are presentation metadata only. They never rename, reorder, add, or remove TIFF samples and they never alter Photoshop Spot Channel resource names. Adjustment keys and export separations continue to use the TIFF's real channel names.

The application always provides two read-only built-in palettes:

- CMYK — International
- RGB — International

Users can define any number of custom palettes in global Settings. A custom palette contains ordered display slots with a UI name and RGB accent color. If a TIFF has more channels than the selected palette has slots, remaining channels use their TIFF names and deterministic fallback colors.

Settings stores the reusable custom-palette library and the default palette selection for new projects. A project's selected palette is copied into the `.shade` file (schema v6), so the project retains the same visual channel aliases/colors on another workstation even if that workstation does not have the custom palette in its global library.

The Channels panel can switch the active project palette at any time. Changing the project palette is a project modification and is saved with the `.shade` file.
